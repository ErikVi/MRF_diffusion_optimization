# Generated results

Experiments write arrays, plots and run metadata here by default. Other generated
runs are ignored by Git, but the completed full worked example is intentionally
versioned, including its report, figures, numerical arrays and provenance.

- [Illustrated report (GitHub-readable Markdown)](complete_worked_example/full/report/REPORT.md)
- [HTML report (download the run folder to view locally)](complete_worked_example/full/report/REPORT.html)
- [Full run directory](complete_worked_example/full/)
- [Sequence and information summary](complete_worked_example/full/summary.csv)
- [Reconstruction metrics](complete_worked_example/full/reconstruction_metrics.csv)

GitHub renders the Markdown report and its linked PNG figures. Download or clone
the whole run directory to use the HTML report with its relative image links.
Use a new run name for repeats; the experiment refuses to overwrite this archive.
